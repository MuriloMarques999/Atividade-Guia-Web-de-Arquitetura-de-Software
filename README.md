# Guia Web de Arquitetura de Software

Atividade desenvolvida para a unidade curricular de Gestão de Projetos do curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas (SENAI).

**Equipe:** 
- Murilo Marques Dantas Vieira
- João Vitor Nogueira Alves

## Nota sobre o uso de IA
De acordo com os requisitos da atividade, declaro que ferramentas de Inteligência Artificial foram utilizadas para gerar a estrutura de código (HTML/CSS/JS) e auxiliar na compilação e resumo inicial dos textos de arquitetura, incluindo a funcionalidade de tradução (Português/Inglês). O conteúdo gerado foi integralmente validado, ajustado e revisado pelos alunos com base nas publicações originais de Martin Fowler para assegurar a precisão e a coesão no que diz respeito aos impactos na gestão de projetos.
